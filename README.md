# demo_PR

A minimalist **neobrutalist** single‑page portfolio that showcases the name **MUKESHWAR RAUDRA J** in the centre of the screen.

## Preview

Open `index.html` in a browser or run a local server:

```bash
python -m http.server 3000
# then open http://localhost:3000
```

![Homepage preview](homepage_preview_1792847617956.webp)

## Features
- Neobrutalist design with a retro dot‑grid background
- Centered name display with subtle hover/click animations
- Small JavaScript for sound effects and color cycling
- Pure HTML + CSS + JS – no build step required

## Font
The page currently loads **Space Grotesk** and **Syne** from Google Fonts. (You can swap the font by editing the `<link>` tag in `index.html`.)

## Development
1. Clone the repository:
   ```bash
   git clone https://github.com/P-r-o-f-e-s-s-o-r/demo_PR.git
   cd demo_PR
   ```
2. Edit `index.html`, `style.css` or `script.js` as needed.
3. Refresh the browser to see changes.
